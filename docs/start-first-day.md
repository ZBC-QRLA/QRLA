### 主要记录电控组遇到的困难与解决

**困难：网络访问**—— 配置过程中最大的阻碍不是软件本身，而是网络——STM32 工具链需要从 ST 意法半导体官网下载，JetBrains 许可证申请与 CLion 安装也依赖境外站点。在直连状态下，直接无法下载，页面加载中断的情况反复出现，安装到快要绝望。。。

**解决**:还好学长们给出的参考文件里有VPN下载的网址，于是我们先安装了VPN工具（魔戒），让 ST 官网与 JetBrains 站点能够稳定访问。网络通了之后，后面"申请许可证 → 下载工具链 → 配置 CMake"这几步才得以顺利完成。

<span style="color:#888;font-size:12px;">然后去注册谷歌账号等网站玩耍浪费了几个小时（）</span>


### 结果与验证

参照工具链文档的做法，我们以 `STM32F103C8T6` 为例走通了一次完整验证：CubeMX 中选择芯片 → `Project Manager` 中把 Toolchain/IDE 改为 `CMake` → 生成代码 → 回到 CLion 填入工程路径 → 在"管理工具链"中把工具链指向 STM32CubeCLT 的编译工具。

点击小锤子编译，CLion 返回"**构建已完成**"。
